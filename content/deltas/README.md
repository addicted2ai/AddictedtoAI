# content/deltas/

Dated capability deltas for the **Impossible -> Routine** showpiece
(`specs/site`). One file per delta: the capability in one plain sentence,
end A (the date it was a research result, with a source), end B (the date it
became routine, with a source), and optionally the price or metric at each
end. A delta with an unsourced end fails the build; deltas are curated, never
auto-generated.
