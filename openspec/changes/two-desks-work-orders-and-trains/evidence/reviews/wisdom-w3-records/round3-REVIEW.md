## 3. The spawned child — what it depends on, and every failure direction
The live date is read by systemToday, called only by liveNow, called only by Check E no record is expired plus two controls that compare live against systemToday and against the pin. Source lines 353 to 383. It builds a fresh area under the OS temp area with mkdtempSync join tmpdir brief-live, writes today.mjs with writeFileSync, copies process.env, deletes TZ, runs spawnSync process.execPath helper with encoding utf8 and the stripped env, demands status zero plus stdout matching slash-d four dash d two dash d two after trim, returns the line, and removes the area in finally with rmSync recursive force. Fail-closed comment says a helper failure throws so a broken clock refuses rather than passing silently.

What it depends on, each with what happens when broken or hostile, and whether the direction is safe. Safe means refuses. Unsafe means passes when it should refuse, or passes a wrong date as right.

- process.execPath. Broken, missing binary: spawnSync throws or returns non-zero, systemToday throws, Check E throws, suite red. Safe. Hostile, binary replaced with one that prints a past date in valid shape: returns valid past, shape check passes, live returns past, an expired wall looks unexpired to the live gate. Unsafe for the live property. Demonstrated in miniature by M15: helper fixed to 2020-01-01 plus expired B2 makes the live gate green while pinned gates still fail. The helper string is the stand-in for the hostile binary; both are valid-format wrong-date returns that the shape check cannot see.
- tmpdir plus mkdtempSync. Broken, unwritable TMPDIR or disk full: throws, Check E throws, red. Safe. Hostile, TMPDIR pointing at a watched area: mkdtempSync still appends randomness, helper still written fresh, no prediction. Safe as far as run.
- writeFileSync helper content. Broken, disk full: throws, red. Safe. Hostile, content edited to UTC getters or fixed past: valid shape, live returns UTC or past date. UTC at this hour shares 2026-09-10 with local, so suite stays 24 pass 1 fail while the corpus convention is broken. Demonstrated by M11. Past greens live for an expired wall, demonstrated by M15 live green. Both unsafe for the live property and unpinned: no RECORD anchors the helper string.
- process.env copy plus delete TZ. Hostile TZ Pacific/Niue: child never sees it, system date ignores it. On POSIX this is the shipped protection. On this Windows machine the protection is inert because the override never taints any read: parent direct 2026-09-10, parent system 2026-09-10, Niue direct 2026-09-10, Niue system 2026-09-10, restored both 2026-09-10, child kept Niue 2026-09-10. Ran in r3rev3-child1 and r3rev3-child2 helpers. The zone control that asserts direct taint plus hardcoded 2026-09-09 therefore fails at baseline with actual 2026-09-10 versus expected 2026-09-09. Two defects in one row: time-brittle, fires only 00:00 to 04:59 local on 2026-09-10 in America/Denver, observed failing at 05:02 local; and platform-brittle, assumes POSIX TZ semantics that Windows Node does not provide. Unavailable rather than hostile: deleting TZ when none was set, or restoring through the system zone, leaves direct and system agreeing, safe.
- spawnSync status. Non-zero, helper syntax error: throws system date helper failed, Check E plus live-versus-pin plus zone controls go red, 22 pass 3 fail. Demonstrated by M12. Safe, fail-closed as claimed.
- spawnSync stdout shape. Empty or malformed: throws bad output, same red. Safe. Valid-format wrong date, past or UTC-coincident: passes shape, returns wrong date. Unsafe as above. The shape check pins format, never value. A past date is the failure direction the fail-closed sentence does not name.
- Trim plus regex slash-d four dash d two dash d two. Loosened or tightened without updating the helper: shape either lets bad through to a later string compare or refuses good dates outright. The three copies of the pattern, pinnedNow plus shapeErrors plus systemToday, are not tied together. Listed in section 2.
- rmSync in finally. Broken, locked area: throws even when the date was good, masking the return with a red. Safe in the refuse direction, noisy. Not run as a separate mutation because forcing a Windows file lock from inside the suite would itself need an outside handle; listed here so the direction is not omitted.
- Machine clock plus system zone. Remain by design and said plainly in source. Clock passing moves expiries from pass to fail; that is the wall working, allowed. System zone moves local dates; corpus convention forbids UTC conversion so the file does not touch it; filed repo-wide and explicitly not this packet. Converting the helper to UTC is not available as a remedy and is not a finding against the wall; that the suite lets it through when dates coincide is the finding, demonstrated by M11.
- BRIEF_RECORDS_NOW pin. Ignored by liveNow entirely. Controls honor it, live ignores it. Demonstrated by live-versus-pin control green at baseline plus M14 plus M15. Safe for the hostile-pin direction. Unavailable, malformed pin: pinnedNow returns null, controls fall back to localToday, safe.
- Runner argv name filter. Outside the child but inside the wider class any outside state that changes a verdict without this file being edited. Filtered to twin E7sfx only or to anchors only, a genuinely expired B2 wall goes 2 pass 0 fail and 1 pass 0 fail respectively while unfiltered goes 20 pass 5 fail.
