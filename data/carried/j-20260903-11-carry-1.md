output_tokens_per_task carries value "~48k at high reasoning (a ~30% rise in average output tokens per task)", and both prose sentences that transclude it already supply that framing themselves. The model entry reads "average output tokens per task rose to {{fact:... #output_tokens_per_task}}, lifting cost per task to {{fact:... #cost_per_task}} at high reasoning", so it renders as "average output tokens per task rose to ~48k at high reasoning (a ~30% rise in average output tokens per task), lifting cost per task to ~$0.58 at high reasoning" — "average output tokens per task" twice, "at high reasoning" twice. content/wiki/org/google-deepmind.md has the same doubling in its "llm-releases prices that sentence" paragraph. Shortening the value to "~48k" fixes both surfaces at once and loses nothing, since the ~30% and the effort level are already in the sentences. Separately, the source attaches "at high reasoning" to the cost-per-task clause, not to the token count — "a ~30% rise in average output tokens per task (to ~48k) lifts cost per task to ~$0.58 at high reasoning" — so dropping it from this value is also the more faithful reading.
