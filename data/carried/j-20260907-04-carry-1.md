The body says "The bound facts above render nothing rather than a dated last-known value". The second half is right and I verified it — data/derived/feed-rows.json holds "z-ai/glm-5.2:free": {"$as_of":null,"$status":null,"$vanished":true} — but the first half is not what a reader sees. resolveFact returns state 'vanished' with a null value, and lib/facts.mjs:271-277 renders that branch as the ABSENT span plus the as-of note, so the page reads "not published — last known value, as of an unrecorded date — the source no longer lists this row". "Render nothing" would fix to something like "render as not published, with no as-of date to show". Worth correcting on its own terms, and doubly so because the standing proposal render-pinned-last-known-for-vanished-rows would make this paragraph flatly wrong if it lands.
