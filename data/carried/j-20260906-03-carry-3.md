`hermes_4_3_claim` ("nearly matches (and in some cases exceeds) the performance of Hermes 4 70B at half the parameter cost") and `psyche_production_first` ("our first production model post-trained entirely on the Psyche network") both carry `volatility: slow`, which the schema defines as re-check within 120 days. Both are fixed sentences in a dated launch post and cannot change; `dated` is the class the spec defines for exactly this ("true as of its date, displayed with the date, never re-checked"). As classed they will enter the overdue sweep in February for a re-check that can only confirm the same bytes. The neighbouring quote fact `psyche`, from the same kind of source, is already classed `dated`.
