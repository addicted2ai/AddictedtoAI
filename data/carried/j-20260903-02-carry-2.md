The post says bartowski's GGUF "had 70,172 downloads by 3 September against 1,130 for the source repo". Both figures are exact — I re-fetched them and got 70172 and 1130 — but the HF API's `downloads` field is a rolling 30-day count, not a cumulative total, and "by 3 September" reads as cumulative. It happens not to matter here (thomsonreuters/ Thomson-1.0-Small was created 2026-08-18, so the 30-day window covers the repo's whole life), but the qualifier is dropped and the same phrasing would be wrong on an older repo. Related: the Sources bullet names "Hugging Face API records for Thomson-1.0-Small, Snowdon1.1-Small, Qwen3.6-35B-A3B and bartowski's GGUF conversion" while linking only the first endpoint.
