The annotation closes "with the same rule deriving `retired` once 2026-09-10 passes." True of the rule's arithmetic, and every annotation of this shape has ended the same way — but the identical clause in j-20260901-08 ("the same rule derives `retired` once 2026-09-04 passes") is falsified today: nex-agi/nex-n2-mini and nex-n2-pro moved their date to 2026-09-08 on 2026-09-02 and are still active-listed on 2026-09-04. Because a date change with no status change emits no change record, the forecast quietly stops being true and nothing in the file says so. The clause should read as conditional on the date holding — one word, and it stops the log making predictions the same log later contradicts.
