The entry declares `- name: Seed / class: manual`. `manual` correctly keeps the linker off it, but neither mechanism that reads this list looks at `class`: `matchProviders` and `orgNameTokens` in `lib/render/frontier.mjs` both map `aliases[].name` with a 3-character floor and nothing else. So `seed` becomes (a) a board-join key that matches any future catalog provider id containing the substring — today only `bytedance-seed`, tomorrow anything a router files under a name with `seed` in it — and (b) an ownership token, making any registrable domain whose bought label is exactly `seed` read as this organisation's own. The alias buys nothing in return, since `manual` means it is never wrapped in prose. Dropping it, or narrowing it to a form that carries the vendor name, would close both without any loss.
