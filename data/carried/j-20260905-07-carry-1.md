The post says "On Claude Code and Hermes Agent the payload runs before the workspace-trust prompt is accepted", inside a paragraph whose other three clauses come straight from Manifold's per-agent case studies. Manifold does not say this about Hermes. Its Hermes trigger reads "A user opens a repository with Hermes and sends their first message, and the payload executes as Hermes gathers that context" — no trust prompt appears anywhere in the Hermes section — and CVE-2026-71963's description says the same ("When a user opens the malicious repository and sends any message"). The claim comes from the aggregator: The Hacker News writes "On Claude Code and Hermes Agent, the payload fires before the workspace-trust prompt is accepted." Everywhere else the post marks aggregator-sourced facts ("per Manifold", "The Hacker News reports", "Stated by" column); this one clause is asserted flat, against the house rule of primary sources over aggregators. Fix: either "The Hacker News groups Hermes Agent with Claude Code here; Manifold's own Hermes case study puts it at the user's first message", or cut Hermes from the sentence and leave it with Claude Code.
