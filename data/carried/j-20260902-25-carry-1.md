The revision correctly moved the Apache-2.0 and four-channel claims onto rows sourced to the documents that state them, but each new row carries `date: "2026-08-28"` and cites a document that does not state that date. The model card's News item ("We open-source **Hy4 preview** and **Hy4 preview-FP8** model weights on [Hugging Face], [ModelScope], [GitCode], and [CNB]", line 127 of the raw README fetched 2026-09-03) is undated, and the LICENSE file carries only "Copyright (C) 2026 Tencent." The date is true and corroborated — the press release is dated 2026-08-28 and the HF repo's `lastModified` is 2026-08-28T14:58:32Z — but each row's own citation supports the event, not the date. The same applies to the `open_weights` fact, whose value ends "on the release date" while citing the undated model card. Adding the press release alongside, or dropping the date qualifier from `open_weights`, closes it. Note the HF API also reports `createdAt` 2026-08-27T08:52:40Z, so the repo predates the announcement — another reason not to hang the publication date on the repo's own documents.
