The org body reads "The about page calls Mercury {{fact:org/inception-labs#product}}", and that fact's value is "diffusion-based large language models (dLLMs); it calls Mercury 'the world's first commercially available family of diffusion large language models'". renderFact (lib/facts.mjs:217) splices the value inline, so the rendered sentence says "calls Mercury ... it calls Mercury ..." twice in one clause. Dropping "; it calls Mercury" from the fact value, or rewriting the lead-in to "The about page describes", fixes it.
