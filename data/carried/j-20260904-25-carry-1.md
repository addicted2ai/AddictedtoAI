The annotation asserts "the successor row" and supports it with vendor, tier, context and price — that is inference from naming, and it is the one judgment in the annotation that is not arithmetic. The same 2026-09-04 snapshot settles it outright and the annotation does not say so: the row `~z-ai/glm-flash-latest`, whose own description reads "This model always redirects to the latest model in the GLM Flash family", carries `alias_target: {"name":"Z.ai: GLM 5.3 Flash","slug":"z-ai/glm-5.3-flash"}`. That is OpenRouter declaring the current GLM Flash model in the feed itself. The next annotation on this row (one is due — the same rule derives `retired` after 2026-09-10) should cite that field, which turns the successor claim from a reading of the names into a quotation of the source.
