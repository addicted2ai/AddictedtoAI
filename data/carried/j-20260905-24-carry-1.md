Five of the seven scripts hardcode the job's own worktree as their root — `const root = 'D:/addictedtoai-worktrees/j-20260905-24'` in tools/measure-design-arena.mjs and tools/measure-design-arena-history.mjs, `const OUT = 'D:/addictedtoai-worktrees/j-20260905-24/data/reviews/evidence/...'` in tools/fetch-design-arena-terms.mjs, the same prefix throughout tools/append-evidence-transcripts.mjs, and it is the default of `process.argv[2]` in tools/scan-out-for-design-arena.mjs. That worktree does not survive the merge, so `node tools/measure-design-arena.mjs` from the repository root will fail on a path that no longer exists — while the evidence file states the scripts were "kept so the run reproduces rather than being described". The two pre-existing scripts in the same directory (tools/ui-evidence.mjs, tools/ui-invariants.mjs) hardcode no absolute path. Deriving the root from `process.cwd()` (or an argv override, as scan-out-for-design-arena.mjs already half does) would fix all five.
