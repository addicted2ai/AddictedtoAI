The evidence file now carries two same-day, same-URL byte counts with no note that they are expected to differ — the table row says "HTTP 200, 375,916 bytes of served HTML, fetched 2026-09-04" and the correction blockquote below it says the UA-only fetch returned "HTTP 200, 376,021 bytes" on 2026-09-04. Both are correctly attributed to their own run, but a later reader comparing them has nothing telling them which of "the page changed", "the measurement is unreliable" or "these are different documents" applies. Re-fetching from this machine during the review returned 376,064 bytes and, seconds later, 376,065 — so the served size genuinely drifts run to run. One clause on the table row ("served bytes vary between fetches; the counts below are per-run") would settle it.
