The body says "Bedrock is also the only endpoint OpenRouter lists behind each Nova row". Measured against https://openrouter.ai/api/v1/models/amazon/<slug>/endpoints on 2026-09-06: nova-2-lite-v1, nova-lite-v1, nova-micro-v1 and nova-pro-v1 each return TWO endpoint records and nova-premier-v1 returns one — every one of them with provider_name "Amazon Bedrock". The claim the measurement supports is about the provider, not the endpoint count, so "the only endpoint provider OpenRouter lists behind each Nova row" is the sentence that survives a reader checking it.
