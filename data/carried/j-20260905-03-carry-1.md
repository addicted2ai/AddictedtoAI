`data/sources/README.md` opens by enumerating what `registry.json` declares — "URL, the fields it yields, which field is the row id ..., `fetch_every_days`, `expected_change_days`, an optional `mints` mapping, its robots/terms check result, and the date that check was made". The new optional `declined_fields` key is absent from that list, though the module docstring in `pulse/lib/registry.mjs` was updated to name it. A reader who opens the directory's own README to learn the registry's shape will not learn the key exists — a mild instance of the exact "you cannot tell what has been decided" problem this change was made to end. Fix: extend that sentence with "the optional `declined_fields` refusals (a path this repo has looked at and deliberately does not carry, each with its `decided_on` date and the measurement behind it)".
