# data/proposals/rejected/

The rejection index (`specs/loop`). A rejected proposal lands here with the
rejection reason appended. Duplicate suppression is deterministic and exact:
a new proposal whose `slug` equals one here is auto-discarded with a pointer
to the earlier reason, spending no inference. Differently-worded
resubmissions are caught by the reviewer — this index travels in the review
checklist — never by fuzzy matching.
