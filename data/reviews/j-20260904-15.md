## Is a non-verbatim `cited` value allowed

Checked, because the edit deliberately departs from the source's wording.
`openspec/specs/wiki/spec.md:58-60` defines `cited` as "a manual value with a
`source_url` and an `accessed` date" — the verbatim requirement in that spec
(lines 464-487) and in `specs/pulse` (line 326) is about **feed**-bound facts
("a feed-bound fact remains what its source says, verbatim"). Nothing requires
a `cited` value to be the source's exact words, and the same entry's other
`cited` values are already paraphrases ("GPT-5.6 Sol; API stable alias
gpt-daybreak-blue-latest"). No `spec-violation`.

I also checked that nothing else in the corpus presents this sentence as a
quotation, which would have made the substitution a doctored quote:
`grep "mainline model" content/` returns exactly one file, this entry, at the
`blue_definition` value. `blue_definition` is transcluded once, in this entry's
prose, not inside quote marks.
