**`orgOwnDomains` implements the recorded half with a name-token filter** — the
judgment the author took beyond D2's edit text and disclosed in `proposal.md`
item 1, citing `lib/render/frontier.mjs:317-326`. That range is exactly the
function:

```js
function orgOwnDomains(org) {
  const tokens = orgNameTokens(org);
  const domains = new Set();
  const cited = [...(org?.data?.facts ?? []), ...(org?.data?.timeline ?? [])];
  for (const item of cited) {
    const reg = registrable(urlHost(item?.source_url));
    if (reg && reg.label.length >= 3 && tokens.has(reg.label)) domains.add(reg.domain);
  }
  return domains;
}
```

The filter is real and the citation is accurate to the line. The author's stated
reason for writing it in — an unfiltered "records citing itself from" would admit

measurement above, so it holds. R13's *prose* does state that half unfiltered,
which the author says plainly and flags as the one sentence to cut if the round
meant otherwise. That disclosure is the right handling of a divergence between a
rule's prose and its enforced implementation. It does leave the restored clause
