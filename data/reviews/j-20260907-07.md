## Finding 3 — the mention, and whether the rail actually fills

This is the only one of the three that is a claim about what the machinery does,
so it is the one I measured rather than read.

The mention is present: line 11 of the post's front matter is
`  - concept/covered-models`, and `content/wiki/concept/covered-models.md`
exists carrying `id: concept/covered-models`. A bogus mention is a build error
in this repository, and the loop's `npm run build` passed on this commit, so the
id resolves.

I could not run the backlink computation directly — this review worktree has no
`node_modules` at all (`ls -ld .../node_modules` → `No such file or directory`),
so `lib/corpus.mjs` cannot even load `fast-glob`, and creating one is forbidden
here. So I measured the input instead and read the fold.

`buildBacklinks` (`lib/mentions.mjs:29-50`) is an unfiltered fold: for every doc
in the corpus, for every id in `doc.data.mentions`, push `{url,title,type,file}`
onto `map[id]`. `renderAppearsIn` (`lib/mentions.mjs:73-77`) renders the rail
whenever that list is non-empty and renders nothing when it is empty. So the
rail's contents are exactly the set of content files whose `mentions` list holds
the id. Grepping the whole of `content/` for `concept/covered-models`:

```
content\blog\anthropic-enterprise-frontier-safeguards.md:11:  - concept/covered-models
content\wiki\concept\covered-models.md:2:id: concept/covered-models
content\wiki\concept\covered-models.md:118:{{fact:concept/covered-models#fable_mythos_relationship}} ...
content\wiki\concept\covered-models.md:131:{{fact:concept/covered-models#affected_organizations}}. ...
content\wiki\concept\covered-models.md:138:{{fact:concept/covered-models#efs_rollout}}. ...
```

Exactly one mentions-list hit, and it is the post. The other four are the
entry's own id and its own self-transclusions, which are not mentions and do not
enter the fold. So the entry's "Appears in" rail goes from empty to one item
naming the post — which is precisely the state the finding said was wrong and
precisely the fix it asked for.
