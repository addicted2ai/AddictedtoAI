# CP-UI-001-1 — Dated Ledger

```yaml
id: CP-UI-001-1
version: 1
schema: loops/ui-loop/graph/schemas.md#concept-packet
depends_on: [BRIEF-UI-001.v1]
name: Dated Ledger
core_idea: >-
  Time is the identity. Every template hangs its content off one shared vertical date spine
  (the home rail's `--rail-col`, promoted to a site-wide track), and vertical distance between
  rows is proportional to elapsed calendar time, so release-cadence compression is a shape the
  eye reads before any label. /frontier is that spine at its densest: one column per declared
  index, lead changes as dated knots, gaps as honest blank.
reader_walks_away_with: I could see the field speeding up before I read a single sentence, and every mark had a date and a source.
surfaces: [/, /frontier (new), /catalog, /wiki/<entry> (prose entries), /blog, /tutorials, /impossible-routine]
elements:
  - name: time-scaled spine
    purpose: read cadence as spacing; tap a knot to reach the record
    data_source: data/changes.jsonl, data/derived/status-tables.json, data/sources/llm-releases/latest.json
    empty_state: spine renders with tick marks only and the fixed line "no dated records in this window"
    provenance_label: each knot carries feed id + read date in mono, unchanged from home rows
  - name: index columns (current leaders)
    purpose: see who leads each independently published index today, with the value and the day it was read
    data_source: data/sources/openrouter-models/latest.json, data/sources/registry.json
    empty_state: column collapses to its header + "no index published for this window"; page stands on spine, newest-listings and capabilities rails alone
    provenance_label: "index · <publisher> · read <date>" under every value; never mixed with vendor claims
  - name: lead-change knots
    purpose: see when a lead passed and whether by arrival or by rescoring
    data_source: data/changes.jsonl
    empty_state: no knots; a dotted continuation line and "no lead change recorded yet"
    provenance_label: knot label = snapshot date + feed id
  - name: vendor-claim cell
    purpose: see a vendor's own number beside the index, never merged with it
    data_source: content/wiki/model/*.md (cited facts, when present)
    empty_state: text only, in --muted, "no vendor claim on file"; no pattern, no box
    provenance_label: 'ember-outlined tag "claimed · unverified" + source + accessed date; "verified" only with cited evidence'
  - name: capabilities rail
    purpose: what became routine, proven by execution, or reported, newest first
    data_source: content/deltas/*.md, content/tutorials/*.md, content/blog/*.md, lib/deltas.mjs
    empty_state: rail heading + "nothing dated in this window"
    provenance_label: proof-kind word (became routine / proven by execution / reported) + date + source link
  - name: catalog@390 provider groups
    purpose: scan 396 rows as provider ledgers, open one
    data_source: data/derived/catalog.json
    empty_state: existing "0 rows" state of CatalogFilter
    provenance_label: read-date per row, as today
design_moves:
  type: Charter stack kept (R16); tabular lining numerals via font-variant-numeric on every date and value; dates set in mono at --step--1 as the spine face
  colour: paper/ink only; --accent for links, --ember reserved for state flips (deprecated, retired, lead change); no fills
  layout: spine track = --rail-col on every template at >=48rem; below, the spine folds to a left hairline with dates inline; proportional spacing clamped between one and eight row heights
  motion: none
reuses:
  - {surface: /, nearest_existing: lib/render/home.mjs date rail, differs: spacing becomes time-proportional; Frontier door is a spine excerpt}
  - {surface: /frontier, nearest_existing: lib/render/home.mjs rail + delta.mjs pair block, differs: new render module composing existing rail rows into per-index columns}
  - {surface: /wiki/<entry>, nearest_existing: lib/render/entry.mjs, differs: title + first paragraph precede facts (F-K12); facts and timeline share the spine track, filling S18's dead column}
  - {surface: /catalog, nearest_existing: lib/render/catalog.mjs + app/_components/CatalogFilter.tsx, differs: below 34rem rows group into <details> per provider with a count; desktop table unchanged}
  - {surface: /blog /tutorials /impossible-routine, nearest_existing: blog.mjs, tutorial.mjs, delta.mjs, differs: date column moves onto the shared spine track only}
fence:
  a11y: no new controls; <details> is native; spine is decorative CSS (aria-hidden) with dates remaining in text flow
  reflow_320: spine folds to inline dates below 48rem; every grid track minmax(0,1fr)
  payload: zero new client JS; CatalogFilter unchanged
  digit_free_fixed_copy: every rail on /frontier inside [data-derived]; template copy has no digits
  no_external_origins: no new typeface; local() stack only
known_risks:
  - proportional spacing at eight-day snapshot depth yields a spine with little visible variation until history accrues
  - lead-change knots are an empty state on day one; the flagship reads sparse
  - time-proportional gaps can fail R8 row-tracking on wide rows
open_questions:
  - "keeper: R13 track discipline — a third declared track (the spine) on every template; propose amending R13 to three tracks with the spine as a rail, not a content column"
  - "measure: does a time-proportional rail read as cadence to a person, or as ragged spacing"
  - "evidence-fix: rig must capture /frontier at all three widths and both themes"
build_estimate:
  files: [app/globals.css, lib/render/home.mjs, lib/render/entry.mjs, lib/render/catalog.mjs, lib/render/common.mjs, app/page.tsx]
  new_files: [lib/render/frontier.mjs, app/frontier/page.tsx]
```

The bet is that structure can convey pace without a single adjective: spacing is the argument.
