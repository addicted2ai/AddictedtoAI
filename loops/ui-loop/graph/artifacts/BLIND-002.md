## Verdict

**RESOLVABLE from the record: option A.** `domains` is optional on a flagged record; absent means
general by K38's own rule; the Frontier's domain section renders a general lane under the same
three-most-recent rule beside the tagged lanes.

## What anchors A

- **K38, verbatim**: "general" is the UNMARKED default and `text` is not a tag. Absence is therefore
  not a missing value — it is a *stated* value in the vocabulary. `EN-domain-facet` §1: the facet is
  "set-valued, optional … the empty set is legal and common"; §4.1: "drop `text` and let absence mean
  'general'"; DESK-ORDER-001 §3: "untagged = general". A gate that fails a record for carrying the
  vocabulary's default value contradicts the vocabulary.
- **The ≥1 bar is a pre-K38 artifact, not a separate decision.** K30 (keeper, via
  HANDOFF-ORCHESTRATOR §5: "a flagged story must carry at least one domain") was spoken while the
  recommended vocabulary still held `text`. Then, every general story had a value to carry and the bar
  excluded nothing. K38 removed the value; the bar silently acquired an editorial effect no ruling
  states. This does not overturn K30 — it restores K30's effect at the time it was made.
- **B voids criteria the same ruling wrote.** F2 (a rescoring that moved a leader), F4 (a verbatim
  vendor claim) and F5 (a frontier model withdrawn, gated, or opened) describe events with no
  modality. The four posts the proposal names (filing, regulator RFIs, licence gate,
  system card) are F5/F4/F2 shaped. Keeping the bar makes the keeper's own criteria
  unreachable and the flag inert on the one surface the flag exists to populate. That is a
  transcription consequence, not a keeper choice.
- **C is excluded by K38's text.** An explicit `general` value is the marking K38 refused; it re-opens
  EN §6 q1, already closed.

## Scope of the ruling, and what it does not settle

A is a *data* ruling: the build gate drops `domains` from required-when-flagged and keeps the
closed-vocabulary check on any value present. The general lane's **placement** is not fixed by the
record — EN §4.8 orders sections by domain id and "general" has no id — so the lane's position is a
presentation detail for BRIEF-UI-002, bounded by K30 (three most recent by `anchor.date`, quiet-lane
empty state as in §1's display contract). This is not escalated: under K40 it is far short of
"insane catastrophic project threatening", and it removes a restriction no keeper statement imposed
deliberately.
