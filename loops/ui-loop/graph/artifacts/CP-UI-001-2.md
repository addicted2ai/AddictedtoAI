# CP-UI-001-2 — Players Board

```yaml
id: CP-UI-001-2
version: 1
schema: loops/ui-loop/graph/schemas.md#concept-packet
depends_on: [BRIEF-UI-001.v1]
name: Players Board
core_idea: >-
  The identity is a printed tabulation: one dense, ruled grid system (a departures board) carried
  onto every template, set in a self-hosted OFL grotesk for labels with the Charter stack kept for
  prose. /frontier is the board itself: rows are organisations, columns are what the repo can
  state today about their current models (newest listing, price in/out, context, index positions
  where published, vendor claim cell), and every cell that has no source is drawn as an honest
  hatched blank, so the shape of what is unknown is as visible as what is known.
reader_walks_away_with: I read the whole field on one screen, saw exactly which cells the site could not fill, and trusted the rest because of it.
surfaces: [/, /frontier (new), /catalog, /wiki (index), /wiki/<entry>, /wiki/model/<entry>]
elements:
  - name: board rows (organisations)
    purpose: locate a player, read across
    data_source: content/wiki/org/*.md, content/wiki/model/*.md, data/sources/openrouter-models/latest.json
    empty_state: an org with no model row in the feed renders its name and a full row of hatched cells
    provenance_label: feed id + read date in the row's last cell
  - name: current-model cell
    purpose: which model of this player is newest in the feed, and when it appeared
    data_source: data/sources/openrouter-models/latest.json (created), data/sources/llm-releases/latest.json
    empty_state: hatched, "no listing in feed"
    provenance_label: feed id + read date
  - name: price and context cells
    purpose: compare cost and window across players at a glance
    data_source: data/derived/catalog.json
    empty_state: hatched, "not published by source"
    provenance_label: as catalog (source link, read date)
  - name: index position cells
    purpose: where the model sits on each independently published index, when the router republishes one
    data_source: data/sources/openrouter-models/latest.json, data/sources/registry.json
    empty_state: whole column omitted when no index is published; the board stands without it
    provenance_label: "index · <publisher> · read <date>"
  - name: vendor claim cell
    purpose: see the vendor's own figure, walled off from indices
    data_source: content/wiki/model/*.md (cited facts, when present)
    empty_state: hatched, "no vendor claim on file"
    provenance_label: 'tag "claimed · unverified", source, accessed date; verified state needs cited evidence'
  - name: lead-change strip
    purpose: last recorded lead change per index, under the board
    data_source: data/changes.jsonl
    empty_state: strip heading + "no lead change recorded yet"
    provenance_label: snapshot date + feed id
  - name: capabilities column (right)
    purpose: newest proofs, typed by kind
    data_source: content/deltas/*.md, content/tutorials/*.md, content/blog/*.md
    empty_state: heading + "nothing dated in this window"
    provenance_label: proof-kind word + date + source link
  - name: catalog@390 dense rows
    purpose: 396 rows, two lines each, no route change
    data_source: data/derived/catalog.json
    empty_state: existing CatalogFilter empty state
    provenance_label: read date on line two
design_moves:
  type: self-hosted OFL grotesk subset (public/fonts, licence file beside it) for labels, headers, cells; Charter stack for prose; tabular numerals everywhere
  colour: ink on paper; hatched blank = 45-degree --rule stripes; --ember for state flips only; no cell fills
  layout: one board grid with fixed column tokens reused by /catalog and /wiki index; rules on both axes (R8 test passes, values are tracked across); board scrolls in its own container at <60rem
  motion: none
reuses:
  - {surface: /frontier, nearest_existing: lib/render/catalog.mjs table, differs: rows are orgs not models; hatched empty cells; new module reusing catalog cell renderers}
  - {surface: /catalog, nearest_existing: lib/render/catalog.mjs + CatalogFilter.tsx, differs: below 34rem each row becomes two lines (name / in·out·context·status) instead of a stacked record}
  - {surface: /wiki index, nearest_existing: lib/render/entry.mjs index rows, differs: board column tokens; otherwise same rows}
  - {surface: /wiki/<entry>, nearest_existing: lib/render/entry.mjs, differs: lede before facts (F-K12); facts as a board fragment spanning the full measure, retiring the second column (S18)}
  - {surface: /, nearest_existing: lib/render/home.mjs doors, differs: Frontier door is the board's first three rows}
fence:
  a11y: real <table> with scope headers; hatched cells carry visible text, not only pattern
  reflow_320: board inside overflow-x container (R2); page never scrolls sideways
  payload: zero new JS; font is CSS-only; woff2 subset under a stated byte cap in known_risks
  digit_free_fixed_copy: all cells inside [data-derived="frontier-board"]; lede has no digits
  no_external_origins: font files under public/fonts with LICENSE; verify-design allowlist unchanged
known_risks:
  - a self-hosted face adds transfer bytes outside R3's JS bound but inside perceived speed
  - the board is only as wide as the feed's fields; on day one most columns are price and context
  - org-to-model join relies on wiki `feeds` maps; unmapped models fall off the board
open_questions:
  - "keeper: R13 — the board is a third track (fixed column tokens) on /frontier, /catalog, /wiki index; propose declaring it the wide-shell track's own grid rather than a new track"
  - "keeper: R7 measure-list cap does not fit a board; propose exempting board rows"
  - "research: OFL grotesk with a metric-stable subset under 30 KB woff2"
  - "measure: does a hatched blank read as honesty or as breakage to a first-time reader"
build_estimate:
  files: [app/globals.css, app/layout.tsx, lib/render/catalog.mjs, lib/render/entry.mjs, lib/render/home.mjs, app/page.tsx]
  new_files: [lib/render/frontier.mjs, app/frontier/page.tsx, public/fonts/]
```

The bet is that a board full of honest blanks is more persuasive than a page full of numbers.
