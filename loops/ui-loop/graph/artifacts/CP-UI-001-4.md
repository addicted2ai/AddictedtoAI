# CP-UI-001-4 — Provenance Gutter

```yaml
id: CP-UI-001-4
version: 1
schema: loops/ui-loop/graph/schemas.md#concept-packet
depends_on: [BRIEF-UI-001.v1]
name: Provenance Gutter
core_idea: >-
  The identity is the machine's honesty made visible. Every template gains a fixed left gutter
  in which each fact, row, claim and paragraph is stamped with one of three provenance glyphs
  (derived from a feed / cited and unverified / verified by execution) plus its date; the reading
  column stays prose-first. /frontier is organised by provenance state rather than by leader:
  three bands, independently indexed, vendor-claimed, proven by execution, each an honest census
  of what the repo can stand behind today. Amazement comes from rigour legible at a glance.
reader_walks_away_with: I could tell, for every single number, whether the site measured it, quoted it, or proved it, and when.
surfaces: [/, /frontier (new), /wiki/<entry>, /wiki/model/<entry>, /blog/<post>, /tutorials/<t>, /learn/<page>]
elements:
  - name: provenance glyph
    purpose: know the standing of a fact before reading it
    data_source: content/wiki/**/*.md (facts.source feed|cited), content/tutorials/*.md (verified_on), data/derived/sources.json
    empty_state: no glyph; a paragraph with no fact carries an empty gutter
    provenance_label: 'three glyphs with visible text alternates: "derived", "claimed · unverified", "verified"'
  - name: gutter date
    purpose: see when each stamped item was last read, accessed or verified
    data_source: data/sources/openrouter-models/latest.json ($as_of), content/wiki/**/*.md (accessed), content/tutorials/*.md (verified_on)
    empty_state: date omitted with the glyph's text alternate reading "undated"
    provenance_label: n/a (the date is the label)
  - name: frontier band - indexed
    purpose: leaders on each independently published index, with value and read date
    data_source: data/sources/openrouter-models/latest.json, data/sources/registry.json
    empty_state: band heading + "no index published for this window"
    provenance_label: derived glyph + "index · <publisher> · read <date>"
  - name: frontier band - claimed
    purpose: vendor figures, verbatim, walled off
    data_source: content/wiki/model/*.md (cited facts, when present)
    empty_state: band heading + a full-width line "no vendor claim on file for any listed model"
    provenance_label: claimed glyph + source + accessed date
  - name: frontier band - proven
    purpose: capabilities with an executed transcript or dated pair
    data_source: content/tutorials/*.md, content/deltas/*.md, content/blog/*.md, lib/deltas.mjs
    empty_state: band heading + "nothing dated in this window"
    provenance_label: verified glyph + kind word + date
  - name: lead-change lines
    purpose: dated changes of lead under the indexed band
    data_source: data/changes.jsonl
    empty_state: "no lead change recorded yet"
    provenance_label: derived glyph + snapshot date + feed id
  - name: coverage census
    purpose: how many cells each band could fill, printed
    data_source: data/derived/freshness.json, data/derived/sources.json
    empty_state: census line omitted when no band has rows
    provenance_label: derived glyph
design_moves:
  type: Charter stack kept; glyph text alternates in mono at --step--1; band headings in mono tracking; no size change to prose
  colour: glyph colour is the only colour system - --muted derived, --ember claimed, --accent verified; links stay ink-underlined (R9)
  layout: gutter = --rail-col track at >=48rem on every template (the home rail already uses it); below, glyphs run inline before the item
  motion: none
reuses:
  - {surface: /wiki/<entry>, nearest_existing: lib/render/entry.mjs, differs: lede before facts (F-K12); facts stamped in gutter and set at full measure, S18 column retired}
  - {surface: /frontier, nearest_existing: lib/render/home.mjs rail + entry.mjs facts rows, differs: new module grouping rows by provenance band}
  - {surface: /blog/<post> /tutorials/<t> /learn/<page>, nearest_existing: blog.mjs, tutorial.mjs, learn.mjs, differs: gutter track added; body unchanged}
  - {surface: /, nearest_existing: home.mjs, differs: rail becomes the gutter; Frontier door shows the three band counts}
fence:
  a11y: glyphs are inline SVG with text alternates; colour paired with a word always
  reflow_320: gutter folds inline below 48rem; no fixed widths
  payload: zero new JS; glyphs are CSS masks or inline SVG under one kilobyte total
  digit_free_fixed_copy: bands inside [data-derived]; the census is derived, fixed copy has no digits
  no_external_origins: none added
known_risks:
  - a gutter stamp on every paragraph can read as noise on long prose entries
  - "claimed" band is empty on day one; the band heading must not read as a defect
  - three-colour glyph system risks contrast in dark theme for --muted
open_questions:
  - "keeper: R13 - the gutter is a declared rail track on every template; propose an addendum naming a rail track as permitted alongside the two content tracks"
  - "keeper: R-D catalog@390 untouched by this concept; it stands on the other three"
  - "measure: do readers notice and use the glyph, or ignore it (five find-tasks with a why-trust question)"
build_estimate:
  files: [app/globals.css, lib/render/common.mjs, lib/render/entry.mjs, lib/render/home.mjs, lib/render/blog.mjs, lib/render/tutorial.mjs, lib/render/learn.mjs, app/page.tsx]
  new_files: [lib/render/frontier.mjs, app/frontier/page.tsx]
```

The bet is that a reader who can see how each number was earned will trust the site more than one shown a leaderboard.
