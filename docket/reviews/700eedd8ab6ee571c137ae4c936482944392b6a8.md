  The "One limit" paragraph renders the count word and the failing set.
  The changelog itself says "one sweep-dated sentence", so the code
  matches the record; the brief overstates by a word.

  sweep re-run is the truth check (docket Done-when #5), and the changelog

  sweep's own date, which appears nowhere else. The import regex is the
  immediate anti-hardcode gate; this is as strong as a rendered-content
  assertion can be.

  MODULE_TYPELESS_PACKAGE_JSON warning when node imports
  app/lib/one-limit-count.js directly. Cosmetic; exit codes are correct.

  unverifiable; the current run classifies #22 correctly and the fail path
  provably fires, which is the part that matters.
