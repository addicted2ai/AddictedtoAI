## Finding

Blocking: the changelog entry claims "31 of 83 current-era rounds (70, 74, 76, 80, 84–88, 94, 100–101, 104–108, 110–113, 116–120, 122, 124–128) record measured results". The parenthetical enumerates 32 rounds. The discrepancy is round 127, whose Result opens "not shipped", included via the range "124–128"; the symmetric borderline case round 73 (Result "not measured as an outcome" but with measured figures) is excluded. No consistent rule reconciles the enumeration with the count. The fix is a one-line reconciliation — e.g. drop 127 ("124–126, 128"), or state and apply a rule that also admits 73 and changes the count.

Non-blocking observations: the entry's historical sentence "Round 62 wrote the caption when every round did read 'not yet measured'" is loose — rounds 48–53 read "not measured" (without "yet") — though no round before 70 recorded a measured result, so the substance is true.
