## Quoting pins

The paper states that ["emergent abilities cannot be predicted simply by
extrapolating the performance of smaller
models"](https://arxiv.org/abs/2206.07682v2), and the version is named, so the
quotation will still be in the document this URL serves in five years.

## Referring does not pin

For the current state of the scaling literature see [the Chinchilla
paper](https://arxiv.org/abs/2203.15556) and [its
successor](https://arxiv.org/abs/2404.01413). Neither sentence quotes anything,
so both must stay unversioned and both must pass: freezing a reference defeats
the only job it has.

## A quoted term is not a quotation

The idea is usually called the ["scaling
hypothesis"](https://arxiv.org/abs/2001.08361), which names a term rather than
reproducing a sentence, and four words is below the floor this check uses.

## Code is not prose

```text
See "the stock of high-quality language data will be exhausted soon" at
https://arxiv.org/abs/2211.04325 for the original.
```

## Another host is not in scope

The write-up quotes ["something at length from an entirely different
site"](https://example.com/paper) and this check has nothing to say about it.
